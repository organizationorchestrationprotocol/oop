## Initial Commit

- Canonical protocol for organizational work, proportionate governance, independent AI tools, durable decisions and verified effects.
- Relevant instructions loaded as work changes, with explicit authority, compatibility and recovery requirements.
- Runtime adapters connect documented native controls to the protocol and preserve the host's response requirements.
- Concrete corrective guidance for non-authorizing controller outcomes, including evidence, registration, configuration and transport failures.
- Scoped local coordination and persistent diagnostics, with actual presentation acknowledgement and recoverable interruptions.
- Optional attributed session guidance, revision-checked updates and conservative local write exclusion; cached guidance never grants effect permission.
- Action-bound reconciliation combines attributed agent judgments with controller-observed facts, scoped bookkeeping and progress-bound completion.
- Maintainer tools prepare and check runtime instructions without substituting synthetic results for real installation or project outcomes.
- Producer source inventory distinguishes exact structural coverage from unverified obligation semantics and delegated host responsibilities.

Installed runtime/provider interoperability, remote publication, token savings and end-to-end performance are not established by producer checks.
